# Sign Language Gesture Recognition

This project recognizes sign language hand gestures using image processing
and machine learning techniques.

## Technologies Used
- Python
- OpenCV
- MediaPipe
- Scikit-learn
- Streamlit

## Workflow
1. Dataset Collection
2. Hand Landmark Detection
3. Feature Extraction
4. Model Training
5. Web-based Visualization

## How to Run
1. Install requirements
2. Run Streamlit app
